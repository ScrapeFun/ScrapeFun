# ScrapeFun 0.6.7

This update makes it easier to organize your watchlist, set viewing limits for family members, and manage remote devices.

## New features

- Organize your watchlist into groups and manage a title’s groups from its details page.
- Family administrators can set age limits for what members can watch.
- Choose how long a remote device can connect when you approve it.

## Improvements

- Improved Continue Watching, media details, and WebDAV browsing.
- Improved remote reconnection after brief network interruptions.

## Before updating

- Back up your server data and configuration. The upgrade updates the database and restarts the server, briefly interrupting playback and background tasks.
